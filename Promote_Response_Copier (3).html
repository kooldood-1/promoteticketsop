PROMOTE SUPPORT

A good reply in a few steps.

Find the right message, check the facts, and make it fit the ticket.

  1. Find your starting point

    Search an issue or reply code, pick a topic, or open ★ Common replies. Search accepts words in any order and small typos.

  2. Enter the creator’s name

    It appears in every reply automatically. A name is required before you can copy.

  3. Read, then adjust

    Check “Use when” and read the response. It is complete with just the name. Add extra detail only if useful, or edit the message directly. Make sure any claimed checks or fixes have actually happened.

  4. Keep the conversation moving

    Paste the creator’s latest message into “Find the next reply”, or use the follow-up links. Suggestions help you choose; they do not verify facts.

  5. Start fresh for the next creator

    Use “New ticket” to clear the previous name, message and edits. Copying does not send anything.
